# Parley integration

Use Parley for material qualification, commitments, delivery feasibility, commercial/legal/security challenge, and release readiness. Follow the active project's `parley-deck/COOPERATION.md`; this reference does not replace it.

## Disclosure gate

Before E3b, show:

- stable agent IDs, display names, providers/models, and availability;
- exact files/excerpts or allowlist to be disclosed;
- customer, personal, confidential, security, price, contract, and supplier data classes;
- redactions and excluded credentials/secrets;
- confidentiality or provider restrictions; and
- whether the disclosure scope changed since approval.

Obtain tender-scoped approval. Re-gate on provider, roster, packet, scope, or restriction change.

Parley Deck's generic external-backend disclosure default never satisfies E3b. Before any tender-derived brief, excerpt, file or data class is sent, obtain tender-scoped E3b approval for the exact roster, providers, packet/allowlist, redactions and restrictions. No Parley consensus, signoff or default approval satisfies E3b, E5, E6, E7 or E8.

## Dynamic challenge lenses

Allocate across the active quorum:

- qualification and commercial;
- formalities, authority, procedure, and compliance;
- solution and delivery executability;
- release, disclosure, portal, and submission assurance;
- architecture/data/integration;
- security/privacy;
- contract/IP/licensing; and
- SLA/support/operations.

Combine related lenses if needed, but show uncovered material risks and stop if adequate challenge coverage is impossible. Roles are advisory only and never change quorum, ownership, or signoff weight.

## Boundaries

- Participants write their own canonical analysis/review/signoff artifacts.
- Agents never operate procurement portals.
- A solo checklist is not Parley.
- Never silently substitute a model or provider.
- Keep credentials and unrelated private data out of prompts.
- Record human-only decisions and cite the evidence supplied to agents.
- Re-run challenge when a material addendum, price, delivery model, authority, supplier, deviation, or release changes.
