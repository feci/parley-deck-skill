## Safe promotion

Offline synthetic tests may validate an ELViS-shaped declaration but cannot promote the real deployment. Promotion sequence:

1. separate human approval for demo/account/onboarding effects;
2. official demo identity and environment recorded;
3. read-only capabilities observed;
4. staging/final/receipt/withdrawal behavior tested only in the demo;
5. evidence and tested date recorded; and
6. profile changed only after review.

Never create an ELViS account, accept terms, install a signature helper, or use a certificate without E8 approval.
